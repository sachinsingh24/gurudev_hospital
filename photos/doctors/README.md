# Doctor portraits

Name each file after the doctor's slug in `src/data/doctors.js`, for example `dr-mayur-rupavat.jpg`. Then run:

```bash
npm run doctor-photos
npm run build
```

**Only add a portrait with the doctor's consent.**

| File | Source | Consent |
|---|---|---|
| `dr-mayur-rupavat.jpg` | His LinkedIn profile photo (800×800), downloaded 23 Nov 2026 | Dr. Mayur Rupavat agreed to its use on the hospital website, as confirmed by the site owner on 23 Nov 2026 |
